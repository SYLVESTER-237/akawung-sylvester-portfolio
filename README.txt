SPARK PORTFOLIO
1. Install Node.js once from https://nodejs.org (LTS version).
2. Double-click start.bat. The website opens in your browser.
   (Or in a terminal inside this folder:  npm install   then   npm start   then open http://localhost:3000)
3. Admin page: http://localhost:3000/admin  -> upload cover photo, profile photo and designs.
4. Change the admin password: open server.js and edit the line marked CHANGE THIS.
Keep the black window open while you use the site. Close it to stop.
